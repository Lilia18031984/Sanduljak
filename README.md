# 🌤️ Weather Diary

Приложение для ведения дневника наблюдений за погодой с графическим интерфейсом на Tkinter.

## 👤 Автор
**Сандуляк Сергей** 

## 📋 Описание

Weather Diary — это десктопное приложение, которое позволяет:
- Добавлять записи о погоде (дата, температура, описание, осадки)
- Просматривать все записи в виде таблицы
- Фильтровать записи по дате и температуре
- Просматривать статистику (средняя, максимальная, минимальная температура)
- Сохранять данные между запусками программы

## 🚀 Установка и запуск

### Требования
- Python 3.6 или выше
- Tkinter (входит в стандартную библиотеку Python)

```bash
